## 0. Summary

- Create should act as guild engineering infrastructure, not a fourth class.
- Weapon evolution should connect bosses, class identity, materials, quests, lore, and rarity presentation.
- Dragon Disaster should be an event/guild-core defense concept, not random base-destroying dragons.
- Endgame materials such as Allthemodium/Avaritia-style systems must be gated to late or post-endgame use.
- These systems require staged implementation and should not be added all at once.
