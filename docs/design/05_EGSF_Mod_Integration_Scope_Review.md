## 0. Summary

- EG:SF should not accept mods only because they are interesting or requested.
- Each mod must serve Chapter progression, Guild Tier, class identity, Boss Gate, Create logistics, Ad Astra progression, friend-facing value, or backlog purpose.
- Inventory-first means checking current installed mods and existing files before adding anything.
- Experience-filter means judging the player experience and risks, not just technical installability.
- This document is a design evaluation layer and should not replace COMPATIBILITY.md, MODLIST.md, release notes, or packwiz metadata.
