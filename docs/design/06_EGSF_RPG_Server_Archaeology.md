## 0. Summary

- Past RPG servers are useful as player-feel references, not systems to copy directly.
- EG:SF can absorb visible progression, weapon identity, dungeon/Boss goals, loot excitement, and class growth.
- EG:SF should avoid pure grind, safe-spot farming, CPS gameplay, weak numerical-only weapon upgrades, and anti-player progression loops.
- Weapon progression should become guild armory and weapon-line identity, not one mandatory weapon used forever.
- This document should reference legacy research notes rather than duplicating all old server archaeology details.
