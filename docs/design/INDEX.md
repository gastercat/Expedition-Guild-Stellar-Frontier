# EG:SF Design Source Index

`docs/design/` contains design source documents for Expedition Guild: Stellar Frontier. These files are allowed to include design intent, future plans, rejected ideas, backlog items, historical context, and exploratory notes. They are not necessarily the current implementation state.

For current implementation and progression truth, check these sources first:

- `docs/PROGRESSION_OVERVIEW.md`
- `docs/releases/`
- Active FTB Quests files under `config/ftbquests/quests/`
- KubeJS files under `kubejs/`
- Packwiz metadata such as `pack.toml`, `index.toml`, and `mods/*.pw.toml`

Design documents should be read as source material for decisions, not as proof that a system is installed, implemented, balanced, or active in-game.
