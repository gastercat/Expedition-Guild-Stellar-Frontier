# Expedition Guild Stellar Frontier v0.7.4-alpha

## Summary

v0.7.4-alpha is the Chapter 6 mid gear certification MVP gate milestone.

This release adds a verified gear + combat hybrid completion source for Chapter 6. Players now submit mid-tier equipment and material proof, complete a small combat certification, and then claim command rewards that grant:

- `eg.chapter.6.mid_gear`
- `eg.gate.mid_gear_certified`

This is not ItemStages, not a real equipment lock, not a KubeJS equipment check, not a class skill system, and not Palladium / Pufferfish’s Skills integration. It is a low-risk FTB Quests based MVP gate for the campaign control layer.

Known Limitations
The Chapter 6 mid gear certification MVP currently verifies submitted items and small combat tasks through FTB Quests.
It does not inspect equipped gear, enforce class equipment restrictions, or provide real active / passive class skills.
Future work may extend this with ItemStages, KubeJS inventory checks, Palladium, Pufferfish’s Skills, or deeper class progression after those systems are designed and tested separately.
