# v0.7.5-alpha Release Notes

## Summary

v0.7.5-alpha is the Chapter 7 astral license MVP gate milestone.

This release moves Chapter 7 from a mostly semantic astral preparation framework
to an inventory-first license preapproval gate. Players now complete guild
paperwork, survival supplies, launch site marking, Create logistics materials,
and role confirmation before claiming the Chapter 7 GameStages.

Release notes are stored in `docs/releases/`.

## Player-facing changes

- Added a final Chapter 7 license confirmation quest:
  - 公會：星界執照預核准完成確認
- The quest frames Chapter 7 as an Ad Astra expedition license review, not a
  completed launch.
- The task list uses verified vanilla and Create item IDs only.
- No unverified `ad_astra:*` item IDs are required in this phase.

## Chapter 7: Astral license MVP gate

The new Chapter 7 quest grants:

- `eg.chapter.7.astral_prep`
- `eg.gate.astral_license_preapproved`

The gate uses FTB Quests item/checkmark tasks for:

- guild license paperwork
- return navigation
- expedition food
- launch site and outpost lighting
- observation / life support glass
- cargo storage
- launch site marking
- copper and iron engineering materials
- Create logistics parts
- Vanguard / Gunner / Arcanist expedition role confirmation

The existing Chapter 7 command rewards were moved to the final license
confirmation quest so each target stage has one reward source.

## Documentation / planning updates

- `SKILL.md` now includes roadmap memory for future v0.8.0 candidate content,
  TaCZ Gunner planning, Iron's Spells Arcanist planning, magic backend decisions,
  and lightweight guild systems.
- `docs/ROADMAP.md` was added as the long-term planning document, separating
  version direction and feature preview planning from the agent operating guide.

## Technical notes

- This release uses FTB Quests item/checkmark tasks and GameStages command
  rewards.
- No KubeJS gameplay logic was added.
- No Ad Astra recipe, loot, or progression enforcement was added.
- No new mods were added.
- No `ad_astra:*` item tasks were added because Ad Astra item IDs still need
  separate JEI or in-game verification before formal quest use.

## Manual test result

Manual in-game inspection passed:

- Entered game.
- Chapter 7 displayed.
- The new quest displayed correctly.
- No obvious issue was found during manual inspection.

## Known limitations

- This is not a real rocket launch implementation.
- This is not moon progression.
- This is not oxygen system automation.
- This is not Ad Astra progression enforcement.
- This does not detect actual launch pad setup, rocket completion, spacesuit
  readiness, fuel readiness, or off-world travel.
- Future Ad Astra-specific item tasks require in-game ID verification first.
