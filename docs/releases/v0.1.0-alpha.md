# Expedition Guild: Stellar Frontier v0.1.0-alpha

## 版本名稱

v0.1.0-alpha

## 模組包定位

Expedition Guild: Stellar Frontier 是以多人公會遠征為核心的 Minecraft 1.20.1 Forge 模組包。

主軸：
- Create 地表工業化
- RPG 式公會分工
- Ad Astra 太空探索

## 安裝方式

建議使用 Prism Launcher：
1. 建立或匯入 instance。
2. Import `.mrpack`。
3. Java 設定為 17。
4. 啟動後建立新的測試世界。

## 已完成內容

- 模組包可正常啟動。
- 可建立新世界。
- 完成繁體中文 FTB Quests Chapter 0～7 主線。
- Create / Ad Astra / QoL / 地圖 / Waystones / FTB 系統測試通過。
- Create 固定在 `create-1.20.1-0.5.1.j.jar`。
- Ad Astra 固定在 `ad_astra-forge-1.20.1-1.15.19.jar`。

## 測試範圍

## 已知限制

- 伺服器設定尚未凍結。

- 不使用 Ad Astra 1.15.20，除非未來整包遷移到 Create 6。
