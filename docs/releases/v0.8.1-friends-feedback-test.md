# v0.8.1 Friends Feedback Test Release Notes

## Summary

v0.8.1 Friends Feedback Test is a GitHub pre-release for friend-facing early
quest feel and onboarding validation.

This release keeps the v0.8.x technical baseline on Minecraft 1.20.1, Forge
47.4.10, Create 1.20.1-6.0.8, and Ad Astra 1.20.1-1.15.20. It focuses on
Chapter 0 and Chapter 1 quest presentation, early reward feel, and clearer
preview language for Create engineering, Ad Astra foreshadowing, and the
Vanguard / Gunner / Arcanist class fantasy.

## Player-Facing Changes

- Chapter 0 was polished into stronger guild onboarding and expedition
  preparation.
- Chapter 1 was polished to preview:
  - Create engineering department setup.
  - Ad Astra / 星界局 observation and launch-site foreshadowing.
  - Vanguard, Gunner, and Arcanist class fantasy.
- Quest text now matches the v0.8.x baseline:
  - Create `1.20.1-6.0.8`
  - Ad Astra `1.20.1-1.15.20`
- Early quest rewards were adjusted into low-risk guild supply rewards.
