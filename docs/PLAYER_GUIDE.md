# Player Guide / 玩家指南

這份文件給第一次加入 Expedition Guild: Stellar Frontier 的朋友看。

## What This Pack Is / 這包是什麼

Expedition Guild: Stellar Frontier 是 Minecraft 1.20.1 Forge 的 Alpha（測試版）模組包。它的核心是「遠征公會式多人進度戰役」，不是一般 kitchen sink，也不是每個人各玩各的、看到強模組就直接衝到底。

建議玩法是：

- 加入公會。
- 打開 FTB Quests（任務書 / 公會任務）。
- 讀目前章節要你準備什麼。
- 建立共享基地、公共箱與補給流程。
- 逐步準備討伐、守城演習、Create（後勤與自動化模組）產線，以及 Ad Astra（星界遠征模組）太空遠征。

目前有些系統是任務導引、MVP（最小可行版本）門檻，或 progression framework（進度框架）。不要把未來職業、Boss、災變或後終局內容當成已經完整自動化。

## First 10 Minutes / 前 10 分鐘該做什麼

1. 進入世界後先等一下，不要立刻跑太遠。
2. 打開 FTB Quests（任務書 / 公會任務）。
3. 先讀 Chapter 0，尤其是 handbook（操作手冊）類任務。
4. 看到不熟的物品或方塊，先用 JEI 查配方、用 Jade 看來源。
5. 多人遊玩時，先建立或加入共用的 FTB Teams 隊伍。
6. 找一個臨時公會基地位置：附近要有水、可擴建空間、容易辨認。
7. 如果 Xaero's map 可用，先在地圖標記基地。
8. 先做公共箱，不要讓所有材料分散在私人箱子。
9. Waystones（傳送石）要命名清楚，避免隊友找不到回家點。
10. 跟著公會任務走，不要只照原版生存節奏一直挖礦。

## How To Play With The Quest Book / 任務書怎麼看

FTB Quests 是這包的主要導引。把它當成公會公告板，不是裝飾用選單。

每次不知道要做什麼時，先用任務書回答：

- 我現在該帶什麼？
- 公會現在缺什麼補給？
- 我目前在哪個 Chapter（章節）？
- 這個任務是真正完成門檻、MVP 測試門檻，還是 Placeholder（佔位內容）？
- 誰適合負責戰鬥、偵查、建築、後勤或星界準備？

如果任務要求食物、箭矢、火把、紙、盾牌或 Create 零件，重點通常不是「交一次就好」，而是建立多人隊伍可以重複執行的補給習慣。

## Recommended Multiplayer Jobs / 建議多人暫時分工

這些是目前 Alpha 階段的臨時隊伍工作，不是最終職業系統。

| 暫時工作 | 要做什麼 | 初期建議攜帶 |
|---|---|---|
| Frontline / combat（前線戰鬥） | 帶盾、基礎武器與食物，討伐或守城時保護隊伍。 | 盾牌、食物、火把、備用方塊。 |
| Explorer / scout（探索偵查） | 標記路線、洞穴、資源、危險點與回程路。 | 地圖、火把、紙、標記物、食物。 |
| Builder / base（基地建築） | 規劃基地、公共箱、工作區與通道，讓新玩家看得懂。 | 箱子、告示牌、建材、床、照明。 |
| Logistics / Create support（後勤 / Create 支援） | 建立基礎加工、材料流向與公共補給標準。 | 安山岩、鐵、傳動軸、齒輪、水車材料。 |
| Space preparation（星界準備） | 中後期整理發射場、Ad Astra 材料、食物、氧氣相關準備與返航方案。 | 標籤箱、玻璃、食物、照明、Create 材料。 |

## Vanguard / Gunner / Arcanist

Vanguard、Gunner、Arcanist 是目前的三職業設計方向。

- Vanguard（近戰前排）：近戰、坦克、Boss 壓力、隊伍前線。
- Gunner（槍械遠程）：遠程壓制、守城、清怪、火力支援。
- Arcanist（魔法職業）：魔法方向、控場、功能解法、支援、AOE，未來可能包含治療或召喚方向。

目前 Alpha 狀態：這三條不是完整技能樹。Repo 內已有 FTB Quests 的職業認證與 GameStages（進度標記 / 解鎖階段）基礎，但主動技能、完整裝備鎖與最終職業成長尚未完成。

## What Not To Do / 不建議做什麼

- 不要忽略 FTB Quests，只照原版挖礦節奏玩。
- 不要把所有重要材料都放私人箱。
- 不要用偶然拿到的強裝直接跳過章節流程。
- 不要看到 Placeholder（佔位內容）就以為完整系統已經做好。
- 不要自行升級 Create、Ad Astra 或其他 mod。
- 不要隱藏壞掉的任務、過強 loot、crash；請回報。

## Current Alpha Expectations / 目前 Alpha 預期

這是 Alpha（測試版），內容會調整。

- 平衡可能會改。
- 任務文字與獎勵可能會改。
- 部分章節是 MVP 門檻、Framework（框架）或 Placeholder（佔位內容）。
- 戰鬥、Boss、職業、災變與後終局系統仍在逐步強化。
- 測試回報本身就是開發的一部分。

不知道下一步要做什麼時，先問：「公會現在缺什麼？」然後打開任務書。
