# 進度地圖

## 總覽

| 階段 | 主要玩法 | 進入條件 | 離開條件 |
| --- | --- | --- | --- |
| 0. 入會 | 生存開局與角色分工 | 建立新世界 | 完成前哨站 |
| 1. Create 入門 | 基礎動力與加工 | 取得安山合金 | 建立基本產線 |
| 2. 公會工業 | 自動化、物流、鐵路 | 穩定 Create 零件 | 建立公共倉儲與補給線 |
| 3. 航太準備 | 燃料、氧氣、火箭材料 | 有穩定工業供應 | 完成發射基地 |
| 4. 星界遠征 | 月面與後續星球 | 首次發射 | 建立可返回的前哨基地 |

## 進度門檻

| 門檻 | 需要完成 |
| --- | --- |
| Create 門檻 | 水車或風車、Mechanical Press、Mechanical Saw、基本輸送。 |
| 公會門檻 | 公共倉庫、任務交付箱、材料標籤規則。 |
| 航太門檻 | 燃料、氧氣、太空裝備、發射區安全規範。 |
| 遠征門檻 | 回程燃料、備用裝備、基地定位資訊。 |

## 第一版終局

| 目標 | 判定 |
| --- | --- |
| 完成首次太空旅行 | 至少一名玩家成功往返。 |
| 建立月面前哨 | 有氧氣、儲物、回程方案。 |
| 建立跨職業供應鏈 | 至少三種職業的任務被完成。 |
