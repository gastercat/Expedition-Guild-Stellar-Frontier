# 玩家職業分工

> Note / 注意：這是較舊的參考文件。最新的朋友入門指南請看 [PLAYER_GUIDE.md](PLAYER_GUIDE.md)；目前 Chapter 0-11 進度結構請看 [PROGRESSION_OVERVIEW.md](PROGRESSION_OVERVIEW.md)。

## 核心職業

| 職業 | 定位 | 主要工作 | 適合玩家 |
| --- | --- | --- | --- |
| 工程師 | Create 工業核心 | 動力、產線、加工、機械維護 | 喜歡自動化與機構設計 |
| 探勘者 | 地表與地下探索 | 找礦、標記地形、建立路線 | 喜歡冒險與地圖整理 |
| 航太員 | Ad Astra 遠征 | 太空裝備、燃料、發射、星球基地 | 喜歡階段性大型目標 |
| 後勤官 | 公會供應鏈 | 倉儲、補給、任務交付、基地整理 | 喜歡管理與支援 |

## 分工互相依賴

| 需求 | 主要職業 | 支援職業 |
| --- | --- | --- |
| 建立初期工坊 | 工程師 | 後勤官 |
| 找到穩定礦源 | 探勘者 | 工程師 |
| 建立發射基地 | 航太員 | 工程師、後勤官 |
| 月面前哨長期運作 | 航太員 | 後勤官、探勘者 |

## 伺服器規則建議

| 規則 | 目的 |
| --- | --- |
| 任務交付需標註貢獻者 | 鼓勵多人協作。 |
| 大型產線需標示開關 | 降低伺服器負載。 |
| 太空遠征需至少兩人準備清單 | 降低裝備遺失與卡死風險。 |
